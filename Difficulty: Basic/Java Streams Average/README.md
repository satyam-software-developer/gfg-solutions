<h2><a href="https://www.geeksforgeeks.org/problems/java-streams-average/1?page=1&category=Java&status=unsolved&sortBy=submissions">Java Streams Average</a></h2><h3>Difficulty Level : Difficulty: Basic</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18px;">Given an integer array <strong>arr[],</strong> return the<strong> average </strong>of the array using streams.</span></p>
<p><span style="font-size: 18px;"><strong>Note: </strong>Average is sum of all elements divided by the number of elements.</span></p>
<p><strong><span style="font-size: 18px;">Examples:</span></strong></p>
<pre><span style="font-size: 18px;"><strong>Input: </strong>arr[] = [1, 2, 3, 4]</span>
<span style="font-size: 18px;"><strong>Output: </strong>2.5</span>
<span style="font-size: 18px;"><strong>Explanation: </strong>sum =<strong> </strong>1 + 2 + 3 + 4 = 10 and average = 10/4 = 2.5</span></pre>
<pre><span style="font-size: 18px;"><strong>Input: </strong>arr[] = [3, 2, 1]</span>
<span style="font-size: 18px;"><strong>Output: </strong>2.0</span>
<span style="font-size: 18px;"><strong>Explanation: </strong>sum =<strong> </strong>3 + 2 + 1 = 6 and average = 6/3 = 2.0</span></pre>
